# Flipvio

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ahror1994/flipvio)

Рабочий self-hosted аналог FlipHTML5 для публикации интерактивных 3D-флипбуков из PDF и изображений.
Проект реализован без внешних npm-зависимостей на базе Node.js встроенных модулей, WebGL2 (шейдерная деформация листа) и Web Audio API.

## Возможности

- Загрузка PDF или изображений (JPG, PNG, WebP) через Drag & Drop в дашборде или через REST API.
- Нарезка на 3 уровня качества:
  - `thumb`: высота 220px для панели миниатюр;
  - `normal`: 110 dpi (q82) для комфортного чтения;
  - `large`: 200 dpi (q88) для масштабирования (zoom).
- Реалистичный 3D-изгиб листа бумаги в WebGL2 вершинном шейдере:
  - Цилиндрический поворот $\theta = p\pi$ вокруг корешка;
  - Изгиб бумаги вдоль нормали листа с мягкостью $uAmp = 0.13$ (или $0.02$ для твёрдой обложки);
  - Интерактивный захват за угол мышью/тачем с неравномерным поворотом $p(v) = p(1 - 0.55|v - grab|)$;
  - Псевдо-перспектива от глубины $scale = 1 + 0.16 \cdot z/W$;
  - Двусторонность листа через `gl_FrontFacing` с зеркалированием координат `uv.x -> 1 - uv.x`.
- Гибридный рендер: в покое отображаются резкие DOM `<img>`, canvas активируется только на время анимации перелистывания.
- Синтез звука бумаги на базе процедурного Web Audio API (3 вариации обычного листа + отдельный глухой звук для твердой обложки).
- Адаптивный режим: двухстраничный разворот на десктопе, авто-переключение в одностраничный режим на узких экранах (< 780px).
- Панель управления (тулбар): миниатюры, зум, автолистание, звук, режим 1/2 страницы, печать, скачивание исходного PDF, шаринг (ссылка и iframe), переход по номерам страниц и deep-linking `#p=N`.
- Редактор параметров оформления (цвета фона, акцент, скорость, звук, RTL, твёрдая обложка).

## Структура проекта

```text
flipvio/
├── Dockerfile
├── package.json
├── README.md
├── server/
│   ├── index.js              # HTTP сервер, REST API и статическая раздача
│   └── lib/
│       ├── db.js             # JSON хранилище
│       ├── multipart.js      # Zero-dependency парсер multipart/form-data
│       ├── pdf.js            # Конвейер растеризации (poppler/magick + Python fallback)
│       └── rasterize.py      # Модуль растеризации страниц
├── public/
│   ├── index.html            # Дашборд управления и загрузки
│   ├── viewer.html           # Интерактивная 3D-читалка
│   └── assets/
│       ├── dashboard.css
│       ├── dashboard.js
│       ├── viewer.css
│       ├── viewer.js         # Ядро WebGL2 и управление ридером
│       └── sfx/              # Синтезированные WAV-файлы звука страниц
└── tools/
    ├── make-sounds.py        # Процедурный генератор звуков бумаги
    └── generate-demo-pdf.py  # Генератор тестового PDF
```

## Быстрый запуск

### 1. Локально (Node.js >= 20)

```bash
cd flipvio

# 1. Сгенерировать звуки (разово)
python tools/make-sounds.py

# 2. Запустить сервер
node server/index.js
```

Сервис доступен по адресу:
- Дашборд: `http://localhost:8080`
- Проверка здоровья: `http://localhost:8080/healthz`

### 2. Docker

```bash
docker build -t flipvio .
docker run -d --name flipvio -p 8080:8080 -v flipvio-data:/data --restart unless-stopped flipvio
```

## Переменные окружения

- `PORT` — порт HTTP сервера (по умолчанию `8080`).
- `FLIPVIO_STORAGE` — путь к каталогу хранения книг и базы `db.json` (по умолчанию `./storage`).
- `MAX_UPLOAD_MB` — максимальный размер загружаемого файла в МБ (по умолчанию `300`).
